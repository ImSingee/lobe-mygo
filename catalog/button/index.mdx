`action.Button` draws a button with the Lobe UI look and returns MyGo's `ui.Element`, so `Clicked()`, `Disabled()` and any style call keep working after it.

## Basic Usage

<GoDemo name="button/basic" title="Basic usage" height={160} source={basic} />

## Variants

`Primary` marks the main action. `Default` and `Dashed` sit on the container with a border, `Filled` uses a neutral fill, and `Text` and `Link` carry no surface until hovered.

<GoDemo name="button/variants" title="Variants" height={120} source={variants} />

## Sizes

`Small`, `Middle` and `Large` are 24, 32 and 40 DIPs tall.
