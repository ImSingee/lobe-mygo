`layout.SortableList` keeps the order in a `*[]T`, naming each item by `key`. Each row builds its handle where it goes by calling the `handle` func it gets. While a row is dragged, a copy follows the pointer, the row fades in the slot it would drop into and the others make room. From the keyboard, Space on a handle picks the row up and drops it, the arrow keys move it and Escape puts it back.
