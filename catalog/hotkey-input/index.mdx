`field.HotkeyInput` records the keys pressed while it has the focus, written as `display.Hotkey` takes them. A shortcut needs a modifier and one other key; one listed in `Conflicts` is refused. While not focused, buttons reset the shortcut to `ResetValue` and clear it.
