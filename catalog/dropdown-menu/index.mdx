`overlay.DropdownMenu` builds a menu from `[]overlay.MenuItem` and returns the `Key` of the item chosen in the frame. The trigger is a button without a look: give it one with `action.StyleButton` or `action.StyleActionIcon`. Arrow keys, Home, End, typing and Escape work as in a native menu.
