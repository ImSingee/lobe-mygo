`field.Upload` shows no file list and sends nothing anywhere: it picks files and gives the ones it accepts to `OnFiles`, for the app to show and upload as it likes. A click or Enter opens the picker, mygo's `Dialog.Open` in a native app and the browser's file chooser on the web; a file from the chooser has no path, so `ReadAll` returns the `Data` read with it, and a file from a native dialog or a drop is read from its `Path`.

## Basic Usage

Content of its own makes the trigger; `action.StyleButton` gives it the look of a button.

## Dragger

`Dragger` takes files dragged from Finder or Explorer too, and lights up while they are over it. A dropped folder gives the files in it, without hidden ones.
