`code.Highlighter` tokenizes with the lexers of mygo's editor, which know about thirty languages by name, alias or extension (`go`, `ts`, `tsx`, `py`, `sh`, `sql`, `yaml`, …); other code shows plain. Tabs are four spaces wide. `code.Theme` and `code.Spans` give the same colors to code drawn elsewhere.
