`choice.ColorPicker` opens its panel below the trigger. The value changes as the controls move; the top half of the compare tile shows the color the picker opened with, and clicking it brings that color back. `Alpha` adds an opacity slider and a percent field.

## Triggers

`ColorTriggerField` shows the hex value like an Input; `ColorTriggerChip` is a round chip for toolbars.
