`form.New` holds a value of the app's own type; controls bind its fields directly, as `&f.Values.Name`. The form keeps the rest: the values it started from, for `IsDirty` and `Reset`, and each field's touched state, error and running checks. A field checks itself as it loses the focus once edited, and as it changes once it shows an error; Submit checks them all and calls `OnSubmit` only when every one passes.

## Validation

`Validate` returns a field's error; `ValidateAsync` runs off the UI thread after it, cancelled when a newer check starts. `Deps` checks a field again when a field it depends on changes.
